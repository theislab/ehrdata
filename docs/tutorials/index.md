# Tutorials

The easiest way to get familiar with ehrdata is to follow along with our tutorials.
Many are also designed to work seamlessly in Binder, a free cloud computing platform.

**The notebooks can be followed in this order:**

1. **[Getting Started](getting_started)** - Learn the basics of the `EHRData` data structure
2. **[Reading EHR data](reading_data)** - Read wide tables, event tables, MEDS, FHIR, h5ed, and zarr into `EHRData`
3. **[Real Dataset Example: PhysioNet 2019](real_dataset_example_physionet2019)** - Work with a public clinical dataset
4. **[OMOP Introduction](omop_intro)** - Learn how to read OMOP data into `EHRData`
5. **[OMOP Machine Learning](omop_ml)** - Quickstart to ML workflows based on an OMOP dataset
6. **[Interactive Visualization](interactive_visualization)** - Explore your data interactively with Vitessce
7. **[Advanced: Data Management with LaminDB](lamindb)** - Store, share, and track datasets in the cloud
